# code unwell - Landing Page Specification

## Project Overview
- **Project name**: code unwell landing page
- **Type**: Single-page marketing landing site
- **Core functionality**: Dark-themed landing page promoting a tech education platform teaching Data Science, AI, and coding
- **Target users**: Aspiring developers, career changers, tech enthusiasts

## Visual & Rendering Specification

### Theme & Color Palette
- **Background**: Deep charcoal black (#0a0a0f) with subtle noise texture
- **Primary accent**: Sickly green (#39ff14) - "unwell" aesthetic
- **Secondary accent**: Electric purple (#8b5cf6)
- **Text primary**: Off-white (#e8e8e8)
- **Text secondary**: Muted gray (#888888)

### Typography
- **Headings**: "Space Grotesk" - techy, geometric sans-serif
- **Body**: "Inter" - clean readability
- **Accent/Code**: "JetBrains Mono" - monospace for code snippets

### Layout Sections
1. **Hero Section**
   - Large glitchy/distorted title "code unwell"
   - Tagline: "we teach you things that matter"
   - CTA button with glow effect
   - Animated background gradient mesh

2. **Stats Bar**
   - Horizontal strip with key metrics (students, courses, etc.)
   - Glowing accent borders

3. **Course Categories**
   - 3 cards: Data Science, AI/ML, Full-Stack
   - Hover effects with scale and glow
   - Icons for each category

4. **Features Section**
   - 4 feature blocks with icons
   - Staggered reveal animation

5. **Testimonial/Social Proof**
   - Quote with glowing border

6. **CTA Section**
   - Final call to action
   - Newsletter signup form

7. **Footer**
   - Minimal with links

### Visual Effects
- CSS-only glitch text effect on main title
- Subtle animated gradient background
- Glow/shadow effects on interactive elements
- Smooth hover transitions (0.3s ease)
- Noise texture overlay

## Interaction Specification
- Smooth scroll behavior
- Hover states on all interactive elements
- Form input validation (email format)
- No external dependencies except Google Fonts

## Technical Requirements
- Single HTML file with embedded CSS
- No frameworks - vanilla HTML/CSS/JS
- Responsive design (mobile-first)
- All SVGs inline or embedded
