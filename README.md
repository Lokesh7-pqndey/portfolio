## 🎨 Visual Design Architecture (Sanity.io Heuristics)

- **Color Palette:**
  - Base Surfaces: High-contrast dark (`#0b0b0b`, `#111111`, `#141414`, `#1a1a1a`)
  - Hairline Structural Grid: `#212121` and `#2b2b2b`
  - Accent (Used Sparingly): Sanity vibrant orange (`#fc4404`) for CTAs, active runtime badges, and key focal points
  - Support Accents: `#fd9d7b` (peach highlight) and `#bf3104` (burnt rust)
- **Typography & Scale:**
  - Display Headings: Styled with the metrics of **Waldenburg** (tight tracking `-0.04em` to `-0.045em`, line-height `0.96`)
  - Monospace Workhorse: **IBM Plex Mono** for buttons, runtime metrics, SQL queries, and schema trees
- **Macrostructure:** **Marquee Hero** paired with an interactive **Ghosted Data Studio v2.4** and continuous tech ticker.
